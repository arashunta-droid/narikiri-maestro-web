# なりきりマエストロ iPhone お試し版(Web)

version: 0.1 / 作成日: 2026-09-23

同僚など iPhone ユーザーにコンセプトを体験してもらうための、ブラウザ(Safari)で動くお試し版。
**正式な仕様はAndroid版の `要件定義書.md` が正本**で、このメモは「お試し版で何が違うか」だけを書く。

## 1. 位置づけ

- 要件定義書1.3「コンセプトをiOSユーザーに示すためのプロトタイプ」にあたる。Android版の完成を待たずに先行して作成。
- `prototype/`(アルゴリズム検証用)とは別物。prototype は今後も実験用に残し、こちらは配布用として安定させる。
- 要件定義は当面**別扱い**。拍検出・テンポのロジックはAndroid版と同じものを使うので、Android版でロジックを変えたらこちらにも移植する(下記4)。

## 3. お試し版だけの違い

| 項目 | お試し版 | 理由 |
|---|---|---|
| サンプル音源 | **同梱しない** | 公開リポジトリに音源を置かないため(著作権・容量) |
| 曲の選択 | 「ファイル」アプリから MP3 / AAC(m4a) を選ぶ。**開くたびに選び直し** | ブラウザはファイルの場所を覚えられない |
| 基準テンポの保存 | そのiPhoneのSafari内(localStorage)。キーは「ファイル名+サイズ」 | 同じ曲を選び直せば基準テンポが復元される |
| 画面構成 | 1画面(曲選択・メイン・設定を縦に並べる) | 起動画面なし |
| 画面の常時点灯 | Screen Wake Lock API(iOS 16.4以降) | |
| 縦向き固定 | **できない**。コントロールセンターで画面の向きをロックしてもらう | Safariからは向きを固定できない |
| マナーモード | iOS 17以降は鳴るよう設定(`audioSession.type='playback'`) | それより古いiOSは鳴らない場合あり |
| Apple Musicの曲 | 選べない(DRM付き) | |

センサーの符号がAndroidと逆になる機種がありうる。振り上げで拍が鳴る場合は、設定で「正→負」に切り替えてもらう。

## 4. 今後の方針

- Android版でロジック(4.1〜4.3)を変えたら、`index.html` の対応部分も直す(コード内のコメントに移植元の `.kt` 名を書いてある)。
- 同期の手間が増えてきたら要件定義書に統合する。統合するなら、要件定義書に「プラットフォーム別の差分」の章を作り、この表を移すのがよい。

## 5. 公開手順(GitHub Pages)

1. GitHubで**公開(Public)リポジトリ**を新規作成(例: `narikiri-maestro-web`)。
2. このフォルダの中身(`index.html`, `icon.png`, `README.md`)をリポジトリ直下に置いてpush。
3. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save。
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される。このURLを同僚に送る。

更新するときは、`index.html` を直してpushするだけで反映される(反映まで1〜2分)。

## 6. 同僚への案内文(そのまま送れる)

> iPhoneのSafariで下のURLを開いてください。
> 1. 先にコントロールセンターで「画面の向きのロック」をオンにする
> 2. 「はじめる」→ センサーの利用を「許可」
> 3. 「ファイル」から曲(MP3/m4a)を選ぶ
> 4. 「基準テンポ作成開始」で曲に合わせて1回指揮 → 「この基準を保存」
> 5. 「なりきり再生」で、振る速さに合わせて曲のテンポが変わります
>
> 共有ボタン →「ホーム画面に追加」するとアプリのように開けます。
